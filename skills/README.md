# Skills

Skills são procedimentos especializados que orientam o agente em tarefas recorrentes. Cada skill fica em uma pasta própria e possui um arquivo `SKILL.md` com metadados e instruções.

## Skill disponível

| Skill | Objetivo |
|---|---|
| [Análise de vulnerabilidades](vulnerability-analysis/SKILL.md) | Conduzir avaliação contextualizada, autorizada e defensiva de vulnerabilidades. |

## Como adicionar uma skill

1. Crie uma pasta com nome curto e descritivo.
2. Adicione um arquivo `SKILL.md`.
3. Inclua metadados `name` e `description` no frontmatter YAML.
4. Descreva quando a skill deve ser usada e um fluxo de trabalho verificável.
5. Atualize a tabela de skills em `AGENTS.md`.
6. Documente limites de segurança e referências aplicáveis.
